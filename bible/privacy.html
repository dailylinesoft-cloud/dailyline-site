성경암송과 묵상 개인정보처리방침

시행일: 2026년 10월 8일 · 운영자: 윤동현 / DailyLine Soft · 문의: dhyjnmj@gmail.com

1. 기기에 저장되는 기록

저장한 말씀과 날짜, 묵상과 작성 날짜, 사용자 지정 주제와 추가 구절, 주제·말씀의 사진 배정, 화면 모드·색상·글자 크기와 알림 설정은 기본적으로 기기에 저장됩니다.

2. 선택 기능인 Google 로그인과 Drive 백업

사용자가 백업·복원을 요청하면 Google 로그인을 통해 선택한 계정과 인증 정보를 처리합니다. 인증 토큰은 Google Drive API 요청에 사용됩니다. 앱은 drive.file 권한을 요청하여 앱에서 생성하거나 사용하도록 허용된 파일을 백업·복원 목적으로 처리합니다. Drive 전체 파일에 대한 접근 권한은 요청하지 않습니다.

백업에는 말씀, 묵상, 주제, 사진 배정, 앱 설정과 알림 설정, 백업 생성 시각, 운영체제와 앱 버전이 포함됩니다. 사진 배정은 앱 내 사진의 번호이며 사진 파일 자체는 포함되지 않습니다. 백업은 사용자의 Google Drive에 저장되며 개발자가 운영하는 별도 백업 서버에 전송하지 않습니다.

3. 사용 목적과 공유

Google 계정과 Drive 데이터는 사용자가 요청한 백업·목록 조회·다운로드·복원을 제공하는 데 사용합니다. Google 데이터는 판매하지 않으며 광고, 신용 평가 또는 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.

4. 외부 서비스

Google LLC는 Google 로그인, Google Drive 백업·복원 및 Firebase Remote Config를 통한 앱 공지 제공에 필요한 정보를 처리할 수 있습니다. 외부 서비스의 운영에 따라 필요한 정보가 대한민국 외 국가에서 처리될 수 있습니다. 자세한 사항은 Google 개인정보처리방침을 참조하세요.

5. 보관과 삭제

기기의 기록은 앱에서 삭제하거나 운영체제의 앱 데이터 삭제 기능으로 제거할 수 있습니다. 앱을 제거하기 전 필요한 기록을 백업하세요. Google Drive 백업 파일은 사용자가 Drive에서 직접 삭제할 때까지 남을 수 있습니다. 앱의 Google 계정 연결 해제만으로 기존 클라우드 백업은 삭제되지 않습니다. Google 계정 보안 설정에서 앱 접근 권한을 철회할 수도 있습니다.

복원 전 기록은 기기에 안전 백업으로 저장되며 다음 안전 백업 시 교체될 수 있습니다. 업로드·다운로드용 임시 파일은 작업 후 삭제하도록 처리합니다.

6. 선택권과 문의

Google 로그인을 하지 않고 기기 내 기본 기능을 사용할 수 있습니다. 클라우드 백업은 사용자가 선택할 수 있습니다. 개발자가 직접 보유한 문의 기록 등의 개인정보 열람·정정·삭제 요청은 dhyjnmj@gmail.com으로 보내주세요. 기기와 개인 Drive의 기록은 사용자가 직접 관리할 수 있습니다.

7. 방침 변경

서비스의 데이터 처리 방식이 변경되면 이 페이지의 내용과 시행일을 갱신하고 필요한 안내를 제공합니다.
